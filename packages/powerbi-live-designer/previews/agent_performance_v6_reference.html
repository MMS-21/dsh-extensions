    Simulated event telemetry

    This prototype generates deterministic test tasks, validation results, approval events, and report-view records. Nothing on this page is connected to your Power BI project, agent backend, or actual billing.

    Telemetry fields and metric definitions

    Import a JSON object with a tasks array and an optional usage array. Each task has an ID, date, artifact type, stage flags, quality checks, execution time and token phases. The fields below are used to compute all visible metrics.

    {
  "tasks": [{
    "id": "AGT-001", "date": "2026-11-22", "name": "Sales overview",
    "kind": "Dashboard", "model": "Builder · standard", "charts": 4, "dashboards": 1,
    "generated": true, "validated": true,
    "approved": true, "published": true, "rollback": false,
    "daxChecked": true, "daxPass": true,
    "renderChecked": true, "renderPass": true,
    "refreshChecked": true, "refreshPass": true,
    "rework": false, "revision": false,
    "executionSec": 1440, "waitSec": 600,
    "tokens": {"planning": 10000, "generation": 65000,
      "validation": 18000, "retries": 0, "screenshots": 7000},
    "costUsd": 0.27, "failureReason": null
  }],
  "usage": [{"date": "2026-11-22", "viewerId": "anon-01",
    "reportId": "AGT-001"}]
}

    Verified delivery rate = published, non-rolled-back tasks ÷ started tasks. Time to delivery = execution time plus approval wait on verified tasks. Cost per verified delivery = cost of all attempts ÷ verified outputs. Rework rate = tasks marked rework ÷ tasks generated. Repeat-viewer rate = viewers with usage on at least two distinct dates ÷ unique viewers.

    For production, emit immutable stage events per taskId and artifactId, record token usage by model and phase, keep actual price/rate version for billing, and join published report IDs to anonymized view events. Stage flags in this prototype are a simplified derived representation, not a substitute for an event log.
